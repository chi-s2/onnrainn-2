## 1. あなたはこんな悩みを抱えていませんか？

AIで画像を作れるようになった。
でも――「それで、どうやってお金に変えるの？」

ここで止まっていないでしょうか？

ChatGPTに作りたい画像を伝えれば、以前よりずっと簡単にイラストやキャラクターを作れるようになりました。かわいい女性キャラクターも、動物マスコットも、世界観のあるミニキャラも、思いついた時に形にできます。

ところが、**画像を作れることと、商品を作れることは同じではありません。**

気に入った1枚ができても、次の表情を作ったら顔が変わる。ポーズを変えたら髪型まで変わる。LINEスタンプを作ろうと思ったものの、何種類の表情を用意すればいいか分からない。SNSアイコンも壁紙も気になるけれど、結局どれから手を付ければいいのか決められない。

そうして今日も画像を作り、保存する。明日もまた新しい画像を作り、保存する。気づけばフォルダには何十枚、何百枚と画像が増えているのに、販売できる商品はほとんど増えていない。

もし今の状態に心当たりがあるなら、必要なのは「もっとすごい1枚を作ること」ではないかもしれません。

画像を作れるのに商品化まで進めない大きな原因は、生成技術が足りないからではありません。
**1枚の画像を、1枚で使い切ってしまっていること。** ここにあります。

副業として活用するなら、もう一つ持っておきたい視点があります。それが、

> 「この1枚を、あと何回使えるだろう？」

という考え方です。

気に入ったキャラクターが1体できたら、そこで終わらせない。笑顔にする。驚いた顔にする。挨拶するポーズに変える。服装を変える。春バージョンを作る。スマートフォンや花を持たせる。

そうすれば、最初はたった1枚だった画像が、複数の商品に使える素材へ変わっていきます。

さらに、その笑顔をLINEスタンプだけで使い切る必要もありません。デジタルステッカーにも使える。全身画像ならグッズ向け素材へ展開できる。バストアップに整えればSNSアイコンになる。背景を加えればスマホ壁紙やポストカードにもできます。

つまり、問題だったのは「画像が作れないこと」ではなく、**作った画像を次の商品へつなげる設計がなかったこと**なのです。

## 2. この教材で学べること

今回の教材でやることは、最初から100種類の画像を作ることではありません。
まずは、「このキャラをもっと使ってみたい！」と思える1キャラを作る。そこから始めます。

1. 商品へ展開しやすいキャラクターを設計する（顔立ち・髪型・髪色・瞳・配色・アクセサリーなど、「ここが残っていれば同じキャラに見える」固定ポイントを整理し、正面寄りの全身画像を基準として保存）
2. 基準画像を使いながら、表情 → ポーズ → 服装 → 季節 → 小物の順に差分を増やす
3. できあがった画像を7方向へ展開する
4. 季節・感情・用途・シーンでシリーズ化する

最初から7商品すべてを完成させなくても構いません。SNSアイコンから始めてもいい。壁紙を3種類作ってもいい。表情違いを増やしてスタンプ素材を揃えてもいい。

大切なのは、「次の商品を作るたびに、またゼロから画像を作る」のではなく、**すでに作ったキャラクターを次の商品にも使うこと**です。

今回作りたいのは、単発の「AI画像」ではありません。あとから何度も使える、小さな画像資産です。

## 3. この教材がおすすめな方・おすすめではない方

### おすすめな方

- AI画像を触ったことはあるけれど、作った画像が保存フォルダに眠ったままになっている
- 気に入ったキャラクターをもっと使いたいのに、差分を作ると別のキャラクターになってしまう
- LINEスタンプやSNSアイコン、壁紙などに挑戦したいけれど、商品ごとに何を作ればいいのか分からない
- 毎回クライアントを探して応募・受注・納品を繰り返すのではなく、自分の手元に販売できる商品を少しずつ増やしていきたい

### おすすめではない方・注意点

- この教材は「プロンプトを1回入力しただけで、何もしなくても自動的に月10万円になる」という内容ではありません
- 商品を作れば必ず売れるわけでもありません。売上には価格、商品数、需要、見せ方、集客など複数の要素が関係します
- 教材を読んだだけで何も生成せず、商品も公開しないのであれば、状況は変わりません

お伝えするのは魔法の稼ぎ方ではなく、**AIで作った1枚を使い捨てず、何度も活用できる商品資産へ変えていくためのロードマップ**です。

## 7. はじめに

画像生成AIを使っていると、どうしても「もっときれいな画像を作りたい」「次はもっとすごい1枚を作りたい」と考えやすくなります。もちろん、画像そのものの完成度も大切です。

ただ、副業として活用するのであれば、1枚の完成度だけではなく、**その1枚をどれだけ繰り返し活用できるか**という視点も持っておきたいところです。

最初から何十キャラも作ったり、大量の商品を完成させたりする必要はありません。まずは1キャラを作り、そのキャラクターを深く使っていきます。一度この流れを経験してしまえば、2キャラ目や3キャラ目を作る時にも、同じ考え方を使って商品を増やせるようになります。

## 8. POINT1：商品展開しやすい1キャラを設計する

最初に取り組むのは、これから何度も使っていく基準キャラクターの設計です。
ここで大切なのは、「とにかく豪華で目を引く1枚を作ること」ではありません。

### 8-1. 最初から「あとで使い回せるキャラ」を作る

キャラクターを作る段階から商品化を考えておきます。

- LINEスタンプにするなら、**表情や手の動きを変えやすい**方が使いやすい
- SNSアイコンへ展開するなら、顔や髪型に分かりやすい特徴があり、**小さく表示しても誰なのか判断しやすい**方が向いている
- アクリルキーホルダーなどのグッズを想定するなら、髪や手足、小物が複雑に広がりすぎず、**全体のシルエットがまとまっている**方が扱いやすい

「好きな画像を作ってから使い道を探す」のではなく、「あとから何度も使えるキャラクターを先に作る」という順番に変えるだけでも、その後の作業はかなり整理しやすくなります。

最初から完璧な商品設計をする必要はありません。まずは次の3点だけでも確認しながら作ってみてください。

1. 表情を変えやすいか
2. 全身を別の商品でも使えそうか
3. 特徴を覚えやすいか

### 8-2. キャラクターの固定ポイントを絞る

固定ポイントとは、画像を変えても維持したい特徴のことです。髪型、髪色、瞳の色、基本となる服の配色、アクセサリーなどがこれに当たります。

注意したいのが、**固定ポイントを増やしすぎないこと**です。

| キャラ | 固定ポイントの例 |
| --- | --- |
| 女性キャラクター | 髪型／髪色／瞳の印象／基本カラー／星型のヘアピン |
| 男性キャラクター | センターパート／白・ネイビー・黒の配色／ブルーのブレスレット |
| 動物マスコット | 右耳だけ色を変える／首元に同じスカーフ |

特徴を増やすより、**「何を絶対に残すのか」を先に決めてください。**

### 8-3. 基準画像は豪華さより分かりやすさを優先する

基準画像とは、今後の画像生成で何度も参照する元になる画像です。背景を豪華にしたり、エフェクトを大量に加えたりする必要はありません。むしろ、顔、髪、服装、身体、アクセサリー、全身のシルエットが見やすい画像を優先してください。

基準画像は鑑賞用の作品というより、**キャラクターの設計情報を確認するための「見本」**に近いからです。最初は白や淡い単色など、できるだけシンプルな背景がおすすめです。

基準画像が分かりやすければ、後から別の差分を作った時にも、

- 髪型が変わりすぎていないか
- アクセサリーが消えていないか
- 服の基本カラーがズレていないか

と比較しやすくなります。

### 8-4. 正面寄りの全身画像を基準画像にする

頭から足元までしっかり入り、顔もある程度確認できる大きさの全身画像を作ります。向きは正面、または少し正面寄りにして、両腕や両脚が身体に隠れすぎない自然な立ち姿にしてください。

この構図にしておくと、後からSNSアイコン用に上半身だけを使ったり、全身をそのままステッカーやグッズ向け素材へ展開したりしやすくなります。

基準画像は「一番派手なポーズ」を選ぶ場所ではありません。**そのキャラクターがどんなデザインなのかを、1枚で確認できること**を優先してください。

### 8-5. 一発で完成させず、基準画像を育てていく

最初に生成したキャラクターが、いきなり理想通りになるとは限りません。でも、ここで何度もゼロから作り直す必要はありません。

- 顔は気に入っているけれど服だけ変えたい
- 髪型は理想に近いけれど、もう少し分かりやすいアクセサリーを加えたい
- 全体のデザインは好きだけれど、色の組み合わせを少し整えたい

このような場合は、気に入っている部分を残しながら修正していきます。修正する時も、一度にすべて変えるのではなく、**変更点を絞る**ことをおすすめします。

最終的に「この画像を今後の基準にしたい」と思える1枚ができたら、分かりやすい名前で保存してください。

## 9. POINT2：基準画像を作り、同じキャラの差分を量産する

### 9-1. 変更する要素は一度に増やしすぎない

差分を作る時は変更する項目をできるだけ絞ります。

| 変えるもの | 維持するもの |
| --- | --- |
| 表情 | 髪型・髪色・服装・体型・アクセサリー |
| ポーズ | 顔立ち・服装 |
| 服装 | 髪型・瞳・体型・固定アクセサリー |

画像生成では毎回まったく同じ結果が出るわけではありません。だからこそ、一度に大きく変えるのではなく、少しずつ変化させた方が調整しやすくなります。原因を切り分けられる状態にしておくことで、修正する時も迷いにくくなります。

### 9-2. まずは表情だけを変えて差分を作る

基準画像から最初に作りやすいのが、表情違いです。笑顔、驚いた顔、少し困った表情、悲しそうな顔、落ち着いた笑顔など、表情を増やすだけでも使える場面はかなり広がります。

最初に表情差分から始める理由は、**元画像からの変更量が比較的小さい**からです。

チェックすること:

- 髪型は基準画像と大きく変わっていないか
- 瞳の色や顔立ちは維持されているか
- 特徴として決めたヘアピン・ブレスレット・耳の色・スカーフなどが消えていないか
- 服の基本配色まで変わっていないか

この段階から、「この表情は何に使えるだろう」と考えながら作っておくと、後の商品化がかなり楽になります。

### 9-3. 次にポーズ、服装、季節、小物へ広げる

進めやすい順番は **ポーズ → 服装 → 季節 → 小物** です。

- **ポーズ違い**：自然な立ち姿から片手を上げた挨拶ポーズへ。服装・髪型・固定ポイントは維持
- **服装違い**：変わる面積が大きいので、基本カラーをある程度残して統一感を保つ
- **季節差分**：春は軽い服装、冬は防寒着。顔立ちや髪型、識別ポイントまで一緒に変えない
- **小物追加**：本、スマートフォン、花、バッグ、飲み物など。キャラ本体は変えず、小物で新しい場面を作る

### 9-4. 「完全一致」ではなく「同じシリーズ」に見える状態を目指す

髪の流れ、服のシワ、手の位置のわずかな違い――こうした細かな差まで毎回完全に揃えようとすると、なかなか制作が進まなくなります。

見るべきなのは、**画像を何枚か並べた時に同じキャラクターのシリーズとして自然に認識できるかどうか**です。

特に優先したいのは、顔の印象、髪型、髪色、瞳、体型、基本配色、象徴的なアクセサリー。このあたりが大きく変わっていなければ、多少の細部の違いがあっても同じシリーズとして見せられます。

### 9-5. 崩れやすいポイントを確認しながら修正する

ズレた時は、画像全体を作り直す前にどの部分が崩れているのか確認します。

- 顔の印象が変わったのか
- 髪型の長さや形が違うのか
- 瞳の色が変わっているのか
- 固定していたアクセサリーがなくなっているのか
- 服の基本配色が変わりすぎたのか
- 体型や頭身が別のキャラクターのようになっているのか

問題点を先に整理すると、修正の指示も具体的になります。ここでも、一度に多くの部分を直そうとしないことが重要です。

そして、**必ず基準画像を見返してください。** 差分画像同士だけを比較していると、少しずつズレた状態が基準になってしまいます。差分を10枚、20枚と増やしていくほど、基準画像の存在が重要になります。

### 9-6. 差分は次の商品で使う前提で作る

差分画像は、数を増やすこと自体が目的ではありません。

| 差分 | 想定する用途 |
| --- | --- |
| 笑顔 | 感謝・挨拶のスタンプ |
| 驚いた表情 | リアクション素材・デジタルステッカー |
| 穏やかな表情のバストアップ | SNSアイコン |
| 片手を上げた全身ポーズ | スタンプ・SNS投稿素材 |
| 季節衣装＋背景 | スマホ壁紙・ポストカード |

用途を考えずに「とりあえず50枚作る」と、完成後に何へ使えばいいのか分からない画像が増えてしまいます。1枚ずつ役割を持たせてください。

## 10. POINT3：1キャラを7種類の商品へ展開する

7商品すべてを一気に完成させる必要はありません。まずは一つの商品を完成させ、その時に使った画像や考え方を次の商品へ流用していきます。

### 10-1. LINEスタンプ

背景の細かさよりも、**表情やポーズから感情がすぐに伝わること**が重要です。笑顔、驚き、謝る動き、感謝、応援、おやすみなど、日常会話で使いやすい感情から作っていきます。

- 小さく表示された時にも感情が分かるよう、顔や手の動きを少し大きめに見せる
- 髪型・髪色・瞳・固定アクセサリーはできるだけ変えず、目元・口元・手の動きで感情を表現する
- 背景はシンプルにし、切り抜きや透明背景を想定した構成にしておく

### 10-2. SNSアイコン

全身を見せるよりも、**顔や髪型、キャラクターの識別ポイントが分かりやすい構図**が向いています。基準キャラクターを顔から胸元あたりまでのバストアップ構図へ変換します。

同じキャラクターで表情違いや背景色違いを何種類か作れば、1枚の商品ではなく**アイコンセット**としてまとめることもできます。

### 10-3. スマホ壁紙

キャラクターだけでなく背景や余白も商品の一部になります。注意したいのが、**キャラクターを画面いっぱいに詰め込みすぎないこと**。時計やアプリのアイコンが表示されるため、周囲や上部に適度な余白を残します。

一度基本となる壁紙を作ったら、背景を春夏秋冬へ変えるだけでもシリーズ化できます。朝、夜、星空、カフェ、部屋など、時間帯や場所を変える方法もあります。

### 10-4. デジタルステッカー

すでに作っているLINEスタンプ用の表情差分や全身差分を活用しやすい商品です。デジタル手帳、タブレット、SNS投稿画像などに貼って使うことを想定するため、**キャラクター単体で見た時に分かりやすく、切り抜きやすい構図**にしておきます。

全身が見える画像を使い、キャラクターの外周に白いフチを付けると、ステッカーらしい見た目に整えやすくなります。

### 10-5. アクリルキーホルダー向け画像

**全身のシルエットがまとまっていること**が重要です。髪や手足、小物が大きく外側へ広がっていると、グッズ用のデータとして扱いにくくなる場合があります。

> **注意**：AI画像を作れたからといって、そのまますべての制作サービスで使えるわけではありません。実際にグッズ化する場合は、利用する制作サービスごとに指定されている画像サイズ、解像度、カラーモード、入稿形式、利用規約などを確認してください。画像生成と入稿データの準備は別の工程です。

### 10-6. ポストカード・配布画像

キャラクター単体の素材から、背景を含めた一枚の作品へ仕上げていきます。ポストカードでは**背景そのものも見せ場**になります。

キャラクターを中央に配置するだけでなく、少し左右へ寄せたり、空間を広く取ったりすることで、一枚のイラストとしてまとまりを作れます。ただし、背景を作り込みすぎてキャラクターが埋もれないように注意してください。

スマホ壁紙用に作った季節背景を調整してポストカードへ使うこともできます。同じ背景テーマを縦長では壁紙、横長ではポストカードへ展開するなど、素材の使い方を変えることで商品数を増やせます。

### 10-7. SNS投稿・配信用素材

商品そのものではなく、**販売や発信に使う素材**です。

- キャラクターを画面の片側に配置し、反対側へ文字を入れられる余白を残す
- 告知画像なら中央にキャラクターを置き、周囲へ情報を配置できるスペースを取る
- 案内するようなポーズや指差しポーズを作っておけば、新商品のお知らせや販売ページへの誘導画像に使える

### 10-8. 同じ素材でも用途を変えれば別商品にできる

| 元素材 | 展開先 |
| --- | --- |
| LINEスタンプ用の笑顔差分 | デジタルステッカー |
| SNSアイコン用バストアップ | プロフィール紹介用のSNS素材 |
| スマホ壁紙用の季節背景 | 構図を調整してポストカード |
| 全身の挨拶ポーズ | LINEスタンプ／ステッカー／アクキー向け素材 |

大切なのは、**「商品が変わるたびにゼロから作る」という考え方を手放すこと**です。

- SNSアイコンなら顔を大きく見せる
- 壁紙なら余白を取る
- ステッカーなら切り抜きやすくする
- ポストカードなら背景まで含めて作品として整える

## 11. POINT4：シリーズ化して商品資産を増やす

### 11-1. 1商品で終わらせず横へ広げる

まず確認してほしいのが、完成した商品をそのまま横へ広げられないかということです。

- 壁紙 → 背景や季節を変える
- SNSアイコン → 笑顔／落ち着いた表情／元気な表情へ広げる
- LINEスタンプ →「ありがとう」だけで終わらせず「おはよう」「おつかれさま」「了解」「おやすみ」へ

1つの商品を完成させたら、**「これをあと3種類増やすなら何を変えるか」**と考えるだけでも、シリーズ化の方向が見えやすくなります。

### 11-2. 季節・感情・用途・シーンごとにシリーズ化する

| 軸 | 例 |
| --- | --- |
| 季節 | 春（花）／夏（海・青空）／秋（街並み）／冬（雪景色） |
| 感情 | 笑顔／驚き／応援／お礼 |
| 用途 | 挨拶／仕事中／勉強中／休日 |
| シーン | 朝／夜／カフェ／部屋 |

シリーズ化する時に毎回キャラクター本体を大きく変える必要はありません。顔立ちや髪型、識別ポイントなどは保ち、背景・表情・小物・服装の一部などを変える方が、同じシリーズとして伝わりやすくなります。

最初は大きく広げすぎず、「春夏秋冬の4枚」「表情違いの3枚」のように、**自分が管理しやすい単位**で増やしていきましょう。

### 11-3. 売れた商品や反応の良いテーマを深掘りする

商品を公開した後は、実際の反応も参考にします。

- どの商品が見られているのか
- どの投稿に反応が集まったのか
- どのキャラクターやテーマに興味を持ってもらえたのか

壁紙の反応が良かったのであれば、同じキャラクターで別の季節や背景を増やす。SNSアイコンが購入されたのであれば、表情違いや背景色違いのセットを作る。

1回の反応だけで必ず売れると決めつける必要はありませんが、何も手がかりがない状態で新しいジャンルを毎回考えるより、次に何を作るか決めやすくなります。

### 11-4. 新しいキャラを増やす前に1キャラを深く使う

新しいキャラクターを作る場合、また基準画像を決め、固定ポイントを整理し、差分を作り直す必要があります。一方で、すでに基準画像や差分が揃っているキャラクターなら、その素材を再利用しながら新しい商品を作れます。

**キャラクターを増やすことだけが商品数を増やす方法ではありません。** 1キャラの中で用途を増やすことでも、十分に商品を広げられます。

### 11-5. 基準画像を繰り返し確認して統一感を保つ

基準画像 → 表情差分 → その差分から新しいポーズ → さらに季節差分。このように差分から差分へつないでいくと、少しずつ元のキャラクターから離れてしまう場合があります。

商品一覧を並べて見た時にも確認してみてください。一枚ずつ見ると気にならなくても、並べると髪色や頭身の違いが目立つことがあります。

### 11-6. ファイル名と保存ルールを決めて管理する

早い段階から自分なりの保存ルールを決めてください。

```
hoshi_icon_smile_01
hoshi_wallpaper_spring_01
hoshi_sticker_cheer_02
```

キャラクター名、用途、表情やテーマ、バージョンなど、後から見ても内容が分かる情報をファイル名へ入れておくと管理しやすくなります。フォルダも、基準画像／表情差分／商品用／販売用画像など、自分が探しやすい単位で分けておくと便利です。

せっかく過去に作った素材があるのに、見つからないからまた作り直すのでは効率が落ちてしまいます。

## 13. POINT6：販売ページと営業ゼロの販売導線を作る

### 13-1. 販売ページで「何の商品か」を迷わせず伝える

販売ページを開いた時に、次の4つが分かる状態を作ります。

1. 何の商品なのか
2. 誰に向いているのか
3. 何が入っているのか
4. 購入した後にどう使えるのか

SNSアイコンを販売するのであれば、「オリジナルキャラクターのSNSアイコン5種類セット」のように、商品内容がそのまま伝わる表現にします。

購入を検討している人は、販売者と同じ前提知識を持っているとは限りません。「見れば分かるだろう」と考えず、購入前に知りたい情報を順番に整理しておきます。

### 13-2. 商品の内容・点数・用途を分かりやすく説明する

| 商品 | 書いておきたいこと |
| --- | --- |
| SNSアイコンセット | 何種類入っているか／表情違いか背景色違いか／画像サイズ |
| スマホ壁紙 | 縦長画像が何枚か／季節セットか単一テーマか |
| デジタルステッカー | 表情・ポーズの種類数／想定する使用場面 |

大切なのは、上手そうに見える文章を書くことではなく、購入する側が**「自分が買ったら何を受け取れるのか」を想像できる文章**にすることです。

**商品名 → 内容 → 点数 → 用途 → 注意事項** の順番で整理すれば、販売文章が苦手でも構成を考えやすくなります。

### 13-3. サムネイルでは情報を詰め込みすぎない

商品名、内容、点数、メリット、使い方、注意事項まで全部詰め込むと、画像を小さく表示した時に何が書いてあるのか分かりにくくなります。

サムネイルでは、まずキャラクターを見せる。その上で、どのような商品なのかが分かる短い情報を加える。詳しい内容は販売ページ本文や2枚目以降の画像で説明すれば構いません。

サムネイルの役割は、すべてを説明することではなく、**販売ページを見てもらうための入口**です。

### 13-4. 販売サービスを一つ決めて商品を公開する

一番避けたいのは、「どこで売ればいいのか」を考え続けて、商品が完成しているのに公開しない状態です。

- デジタル商品（アイコン・壁紙など）→ デジタルデータを扱える販売サービス
- LINEスタンプ → 対応するスタンプ販売サービス
- グッズ → 利用したい制作・販売サービスの入稿条件を確認

サービスごとに必要な画像サイズ、ファイル形式、手数料、利用規約などは異なるため、実際に出品する時は最新の条件を確認してください。

### 13-5. 営業ゼロと「何もしない」の違いを理解する

「営業ゼロ」＝「何もしなくても売れる」ではありません。

必要な作業:

- 商品タイトルを考える
- サムネイルを作る
- 販売ページを整える
- 商品数を少しずつ増やす
- SNSで商品を紹介する

違うのは、**商品が売れるたびにゼロから説明したり、その都度依頼者を探し回ったりしなくてもいい**という点です。一度販売ページを作っておけば、そのページが商品内容を説明してくれます。

### 13-6. 集客先を増やしすぎず、続けやすい場所を一つ選ぶ

X、Threads、Instagram、YouTube、ブログ――最初から一気に広げる必要はありません。発信先を増やしすぎると、それぞれを更新するだけで負担が大きくなり、肝心の商品制作が止まってしまうことがあります。

まずは、自分が普段使っている、または続けやすい場所を一つ選んでください。同じキャラクターを使っていれば、投稿内容が違っていても見た目にまとまりを出しやすくなります。

### 13-7. 商品用キャラクターをそのまま宣伝にも活用する

- 新商品を紹介する時 → キャラクターを片側に置き、反対側に商品名や説明を入れる
- セールや新作のお知らせ → キャラクターに案内するようなポーズを取らせる
- 販売ページへ誘導したい時 → 指差しや紹介ポーズの差分を使う

同じキャラクターが販売ページ、商品画像、SNS投稿に登場すると、全体の印象も揃いやすくなります。

## 14. POINT7：30日ロードマップ

| 期間 | やること |
| --- | --- |
| 1〜3日目 | 基準キャラクターを決める |
| 4〜7日目 | 5種類の差分を作る |
| 8〜14日目 | 最初の1商品を完成させる |
| 15〜18日目 | 2商品目、3商品目へ展開する |
| 19〜21日目 | 販売用画像と販売ページを作る |
| 22〜24日目 | 実際に商品を公開する |
| 25〜27日目 | 見られ方や売れ方を確認する |
| 28〜30日目 | 次に増やすシリーズを決める |

### 14-1. 1〜3日目｜基準キャラクターを決める

プロンプト①〜④から、自分が作りたいものに近いものを一つ選びます。何パターンか画像を生成し、その中から今後使っていきたいキャラクターを一つ選びます。

ここで完璧を求めすぎる必要はありません。顔の雰囲気が気に入っていて、髪型や固定ポイントが分かりやすく、今後いろいろな商品へ広げられそうだと感じられるなら、まずはその画像を基準にして進めます。

最終的に「このキャラクターをこれから何度も使いたい」と思える1枚ができたら、基準画像として分かりやすい名前で保存します。

### 14-2. 4〜7日目｜5種類の差分を作る

プロンプト⑤〜⑨を使い、表情・ポーズ・服装・季節・小物の5種類を作ります。

この段階では、商品数を増やすことよりも**「同じキャラクターとして維持できているか」**を確認することを優先します。途中で顔や髪型が大きく崩れてしまった場合は、⑰の修正用プロンプトも使ってください。

### 14-3. 8〜14日目｜最初の1商品を完成させる

7商品の中から、自分が一番作りやすいと思うものを**一つだけ**選んでください。ここで7商品すべてへ同時に手を出してしまうと、それぞれが途中まで進んだ状態になり、最初の商品を公開できるまで時間がかかってしまいます。

まず必要なのは、「自分で作ったキャラクターを商品として完成させた」という**一周分の経験**です。必要であれば⑱を使って仕上げまで行います。

### 14-4. 15〜18日目｜2商品目、3商品目へ展開する

この時に意識したいのが、**すでに作った画像をできるだけ再利用すること**です。

- SNSアイコンで使った表情をデジタルステッカーへ使えないか
- LINEスタンプで作った挨拶ポーズをアクリルキーホルダー向け画像へ整えられないか
- スマホ壁紙で作った季節背景を、ポストカード向けの構図へ変更できないか

### 14-5. 19〜21日目｜販売用画像と販売ページを作る

⑲と⑳のプロンプトを使い、商品紹介画像やサムネイルを作ります。その後、商品説明文を作ります。

ここで販売ページを細部まで作り込み続ける必要はありません。まずは、購入を検討する人が商品内容を理解でき、**公開できる状態まで仕上げること**を優先してください。

### 14-6. 22〜24日目｜実際に商品を公開する

利用するサービスを決めたら、必要な画像サイズ、ファイル形式、利用条件などを確認し、それぞれのルールに合わせて商品を登録してください。

大規模な宣伝を最初からする必要はありません。まずは、**「自分の商品がインターネット上で購入できる状態になっている」**というところまで進めてください。

### 14-7. 25〜27日目｜見られ方や売れ方を確認する

- どの商品画像が見られているのか
- どの投稿に反応があったのか
- 商品ページまで見てもらえているのか
- 実際に購入された商品はあるのか

購入には至っていなくても、特定のキャラクターや商品だけ反応が多いのであれば、次の商品を考える材料になります。反対に、商品ページまでほとんど見てもらえていないのであれば、商品そのものをすぐ作り直す前に、サムネイルや紹介方法を見直す余地もあります。

### 14-8. 28〜30日目｜次に増やすシリーズを決める

反応が良かった商品の別バージョンを増やすのか、同じキャラクターで新しい商品を作るのか、それとも2キャラ目へ進むのかを考えます。

### 14-9. 月1万円から段階的に商品資産を積み上げる

> **重要**：この方法を実践すれば必ず月10万円になるわけではありません。売上は商品内容、価格、需要、販売場所、集客方法、継続期間などによって変わります。以下の数字は、商品資産をどのように積み上げていくか考えるための**目安・計算例**です。

| 段階 | 考え方 |
| --- | --- |
| 月1万円 | 500円の商品なら20件。1商品が20件でも、5商品が4件ずつでも合計は同じ。どの商品が見られ・クリックされ・購入されたのかを確認する |
| 月3万円 | 反応があった商品に近いシリーズを増やす（壁紙が売れたなら別テーマ、アイコンが売れたなら表情や配色違い） |
| 月5万円 | 単品だけでなく、アイコン複数枚・壁紙セット・ステッカーセット・キャラクター素材セットなど複数の商品構成を検討する |

### 14-10. 1キャラを継続的に使える商品資産へ変える

月10万円を考える時も、「一つの商品を大量に売らなければならない」と考える必要はありません。計算例として:

| 価格 | 件数 | 売上 |
| --- | --- | --- |
| 300円 | 100件 | 30,000円 |
| 700円 | 50件 | 35,000円 |
| 1,200円 | 30件 | 36,000円 |
| **合計** | | **101,000円** |

あくまで計算例です。実際には販売手数料などもあるため、その金額がそのまま手元に残るわけではありません。

ここで見てほしいのは、金額そのものよりも、**価格も商品も一つに固定する必要はない**という考え方です。

## 15. まとめ

1. 商品展開しやすい1キャラを設計する
2. 基準画像を作り、同じキャラの差分を量産する
3. 1キャラを7種類の商品へ展開する
4. シリーズ化して商品資産を増やす
5. コピペ用画像プロンプト20本を使って制作を効率化する
6. 販売ページと営業ゼロの販売導線を作る
7. 30日ロードマップで商品公開から売上づくりまで実践する

最初から大量のキャラクターや商品を作る必要はありません。

まずは1キャラを決め、そのキャラクターを基準画像として保存し、表情やポーズ、服装、季節、小物などの差分を増やしてみてください。そこからLINEスタンプ、SNSアイコン、スマホ壁紙、デジタルステッカー、アクリルキーホルダー向け画像、ポストカード・配布画像、SNS投稿・配信用素材へ広げていきます。

一度作った画像を1回だけ使って終わるのではなく、**「この素材を別の商品にも使えないか」**と考えることで、同じキャラクターから複数の商品を作れるようになります。

まず1キャラ。そして1商品。そこから2商品目、3商品目へ。
