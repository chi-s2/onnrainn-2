# SEO記事制作案件（AIMARKS / SOKUSEN）実行キット

今月末までにSEO記事20本を制作・公開し、公開後のデータ報告、その後のLINE送客まで行う案件用の作業一式。

## この案件の流れ

| STEP | 内容 | 成果物 |
| --- | --- | --- |
| STEP 1 | 指名・関連キーワードでSEO記事を20本制作・公開 | 公開済み記事20本 |
| STEP 2 | 公開URL・本数・狙ったKW・順位・SCデータを報告 | `04-report-template.md` に沿った報告書 |
| STEP 3 | 記事からLINE登録へ送客（営業・クロージングは先方） | LINE導線の設置と継続改善 |

`python3 tools/build.py --list` でいつでも確認できる。

## 進め方の前提

- 記事内の会社情報・サービス内容・料金・実績は、**すべてクライアントの一次情報で裏を取ってから書く**。
  推測で書いた事実は指名検索では即バレるうえ、企業の信用を毀損する。未確定箇所は本文中に
  `{{要確認: ...}}` の形で残し、埋まるまで公開しない。
- 検索順位は保証しない。狙うのは「指名検索したユーザーが求める答えに最短で到達できる記事」を
  20本そろえること。
- 20本は「量産」ではなくクラスター設計。ピラー記事2本（AIMARKSとは／SOKUSENとは）に
  クラスター18本をぶら下げる。

## スケジュール（今月末納品・残り約3週間想定）

| 期間 | やること |
| --- | --- |
| Day 1-2 | LINEで詳細確認（`00-condition-memo.md` の確認項目）、ヒアリングシート回収、サイト公開とSearch Console接続 |
| Day 3-4 | 20記事のタイトル／構成を全確定（`outlines/`）、クライアント確認 |
| Day 5-14 | 本文執筆・公開（1日2本ペース） |
| Day 15-17 | 内部リンク総点検、LINE導線設置、インデックス申請 |
| Day 18-20 | 順位計測・Search Consoleデータ取得、STEP 2報告書作成 |

インデックスされてから順位が動くまでにラグがあるため、**公開は前半に寄せる**こと。
月末に20本まとめて公開すると、報告時点で順位データがほぼ取れない。
