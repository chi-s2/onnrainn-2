# 公開前チェックリスト

1記事ごとに、公開ボタンを押す前に必ず通す。

## 事実確認（最優先）

- [ ] `{{要確認: }}` が本文に1つも残っていない
- [ ] 料金・実績・社数・受講者数など、数字はすべて一次情報に紐づいている
- [ ] 公式サイトの記載と矛盾する箇所がない
- [ ] 会社名・サービス名の表記ゆれがない（AIMARKS / SOKUSEN は原則この表記に統一。
      カナ表記は「ソクセン」記事内など、意図がある場所だけ）
- [ ] 誇大表現・断定表現を使っていない
- [ ] 公式との誤認を招く書き方になっていない（必要なら運営者を明記）

## SEO

- [ ] タイトルに主KWが入っている／全角30字前後
- [ ] ディスクリプション110〜120字、主KWを含む
- [ ] H1は1つだけ、タイトルとほぼ同じ
- [ ] H2/H3の階層が飛んでいない
- [ ] URLスラッグが半角英数、内容と一致
- [ ] 内部リンク3〜5本（ピラーへ1本以上）
- [ ] 発リンクのアンカーテキストが自然文
- [ ] 画像すべてにalt（KWを詰め込まず、内容を説明する文で）
- [ ] 構造化データ（Article、該当すればFAQPage / HowTo）
- [ ] canonical設定
- [ ] noindexが付いていない（テーマの初期設定で付いていることがある）

## 読みやすさ

- [ ] 冒頭300字以内に結論が書いてある
- [ ] 1段落4行以内
- [ ] 同じ文末が3回続いていない
- [ ] 表・箇条書きが1つ以上ある
- [ ] スマホで見て、見出しだけ追って内容が分かる

## CTA

- [ ] LINE導線が3か所（リード直後・中盤・記事末）
- [ ] UTMパラメータが記事ごとにユニーク
- [ ] リンクが実際に開くか、スマホで踏んで確認した
- [ ] 「登録すると何が起きるか」が1行書いてある

## 公開後（当日中）

- [ ] Search Console でインデックス登録をリクエスト
- [ ] サイトマップに反映されている
- [ ] 既存記事から新記事へのリンクを1〜2本追加
- [ ] 記事一覧（`04-report-template.md` §2）に行を追加し、公開日を記入
