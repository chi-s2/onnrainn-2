# 内部リンク設計

## 構造

```
【AIMARKSクラスター】                    【SOKUSENクラスター】
        01 AIMARKSとは（ピラー）                11 SOKUSENとは（ピラー）
              │                                       │
    ┌────┬────┼────┬────┐              ┌────┬────┼────┬────┐
   02   03   04   05   06             12   13   14   15   16
  評判 営業代行 料金  恵比寿 怪しい      スクール カナ  評判  料金 怪しい
    │    │    │                          │    │    │
   07   08   09                         17   18   19
  事例 会社概要 求人                    未経験 卒業後 入会
        │                                       │
       10 営業代行の選び方（集客用）           20 営業スクール比較（集客用）
        └───────────── 相互リンク ──────────────┘
                （運営会社が同じ／両サービスの関係を説明する箇所で）
```

## ルール

1. **クラスター記事 → ピラー記事** は必ず1本張る。アンカーテキストは
   「AIMARKSのサービス全体はこちら」のように、リンク先の内容が分かる自然文にする。
   `こちら` だけのアンカーは使わない。
2. **ピラー記事 → クラスター記事** は、該当する話題に触れた段落から張る。
   ピラー記事の末尾にリンク一覧を置くのも可（ただし本文中リンクを優先）。
3. **クラスター同士**は、内容が実際につながるところだけ。
   「料金 → 評判」「怪しい → 会社概要」など、読者の次の疑問に合わせる。
   関係の薄い記事同士を数合わせで張らない。
4. **集客記事（10, 20）→ 指名記事**へ。ただし比較記事の中でだけ自社を持ち上げないこと。
   選び方の基準を示したうえで、「その基準で見た場合のAIMARKS」に自然に橋を架ける。
5. 1記事あたりの発リンクは**本文中3〜5本**。多すぎると1本あたりの価値が薄まる。
6. リンク切れは毎回チェック。公開のたびに、その記事へ張るべき既存記事も更新する
   （新記事を出したら、既存記事から1〜2本リンクを追加する運用にする）。

- [ ] 関連する既存記事から新記事へ1〜2本
