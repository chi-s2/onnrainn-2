# オンライン秘書タイプ診断ページからの導線案

このリポジトリにある診断ページ（`index.html` / `script.js` / `style.css`）は、
読者層がMySTARの対象ユーザーとほぼ重なっている。

- 診断ページ：在宅ワークを始めたい人向け、5タイプ判定
- MySTAR：20〜40代女性、非IT職から在宅ワークへのキャリアチェンジ

診断を終えた直後は「次に何をすればいいか」を探している状態なので、
記事より成果につながりやすい。ただし条件を整えないと規約違反になるので、順番に書く。

---

## 先に：やるなら必須の対応

### 1. ページに広告表示（PR表記）を出す

A8の規定で、広告と分かる表示を一般消費者が見える位置に置く必要がある。
診断ページに成果リンクを置くなら、**診断開始前のファーストビュー**に注記を入れる。
結果画面だけに書くのは「ファーストビュー等」の要件として弱い。

`index.html` の intro セクション冒頭に入れる例：

```html
<p class="ad-notice">※本ページには広告（アフィリエイトリンク）が含まれます。</p>
```

```css
.ad-notice {
  font-size: 0.78rem;
  color: #6b7280;
  margin-bottom: 12px;
}
```

### 2. 男性の扱い

成果条件の対象ユーザーは女性。CTAのラベルに「女性向けの無料相談会です」と添えておくと、
対象外の人が申し込んで否認になるのを減らせる。

### 3. 再訪問期間が「初回のみ」

クッキーが残らないので、リンクを押してその場でLINE追加まで進んでもらう必要がある。
ボタンの文言を「詳しく見る」ではなく「LINEで無料相談の枠を見る」にして、
押した先で何をするかを先に伝える。

### 4. 既存のLINEボタンとの併存

いま結果画面には自分の公式LINEへのボタン（`lineButton`）がある。
そこにMySTARのボタンを並べると、自分のリスト獲得と広告成果が食い合う。

おすすめは **自分のLINEを第一CTA、MySTARを第二CTA** にする形。
自分のLINEに入った人へは後からメルマガやnoteでMySTARを案内できるので、
長い目で見るとこちらのほうが取りこぼしが少ない。

## タイプ別の見せ方

5タイプそれぞれに、MySTARへつなぐ角度を変えた一言を出す。
全タイプに同じ文言を出すと広告感が強くなるので、診断結果と地続きにする。

| タイプ | つなぎの一言（案） |
| --- | --- |
| 事務サポート | 事務スキルにWebデザインが乗ると、単価の高い案件に手が届きます |
| SNS運用サポート | バナーや投稿画像を自分で作れると、任される範囲が一気に広がります |
| AI活用サポート | AIとデザインを両方使える人はまだ少なく、AIを扱えるのは強みになります |
| ライティングサポート | 記事にアイキャッチや図解を添えられると、依頼が途切れにくくなります |
| 経理サポート | 業務の幅を広げたいとき、Webスキルは相性のいい第二の柱になります |

## 実装イメージ

`script.js` の `results` に `mystar` フィールドを足し、結果画面に第二CTAを出す形。

```js
const results = {
  admin: {
    title: "事務サポートタイプ",
    copy: "...",
    steps: [ /* ... */ ],
    mystar: "事務スキルにWebデザインが乗ると、単価の高い案件に手が届きます。"
  },
  // 他のタイプにも同様に追加
};
```

```js
const links = {
  line: "https://lin.ee/your-line-url",
  note: "https://note.com/your-note-url",
  mystar: "[[A8で発行したアフィリエイトリンク]]"
};
```

`showResult()` の中で、結果に応じた一言を差し込む：

```js
mystarCopy.textContent = resultData.mystar;
mystarButton.href = links.mystar;
```

`index.html` の結果セクション、既存 `.cta-area` の**下**に置く：

```html
<div class="sponsor-area">
  <p class="sponsor-label">PR</p>
  <p class="sponsor-copy" id="mystarCopy"></p>
  <a class="sponsor-button" id="mystarButton" href="#" target="_blank" rel="noopener sponsored">
    補助金対応のWebスクールを見る（女性向け・無料相談）
  </a>
</div>
```

ポイント：

- `rel` に `sponsored` を入れる（Googleの推奨。`noreferrer` は成果計測を壊す可能性があるので使わない）
- `PR` ラベルをボタンの近くにも置く
- 自分のLINEボタンより視覚的に控えめにして、第一CTAを埋もれさせない

## 計測

どのタイプの人がMySTARに進んだかを知りたい場合、クリック時にGA4のイベントを送る。

```js
mystarButton.addEventListener("click", () => {
  if (typeof gtag === "function") {
    gtag("event", "affiliate_click", { program: "mystar", result_type: winningType });
  }
});
```

タイプ別のクリック率がわかれば、つなぎの一言を書き換えて改善できる。

## 判断メモ

この導線を実装するかどうかは、診断ページを何に使っているか次第。

- **自分のLINEリストを増やすのが主目的** → MySTARは第二CTAにとどめる（上の案のまま）
- **診断ページ単体で収益を出したい** → MySTARを第一CTAにしてもいいが、PR表記をより明確に

どちらにするか決まったら実装する。現時点ではページ本体には手を入れていない。
