## 成果条件（噛み砕き）

成果になるのは、次の全部を満たしたときだけ。

1. その広告主を**初めて利用する人**
2. **WEB経由でLINE友だち追加 → 予約** をして
3. **30日以内に無料相談会へ参加**した
4. 対象ユーザーが**女性**

否認されるのは、不正・申込不備・虚偽・いたずら・重複成果、それとリスティング違反。

## ここが落とし穴

### 1. 再訪問期間が「初回のみ」

クッキーが残らない。記事を読んだ人があとから思い出して公式サイトを直接開いても成果にならない。
**クリックしたその場でLINE追加まで終わらせてもらう**設計が必要になる。

対策として記事側でやること：

- CTAを記事の上・中・下の3か所に置く（下だけだと取りこぼす）
- CTAの直前で「LINE追加は30秒で終わる」「その場で無料相談の枠を選べる」と手順を先に見せる
- 「あとで調べてみてください」系の書き方をしない。リンクを踏む理由をその行で完結させる

### 2. 女性向けであることを記事の入口で示す

対象ユーザーが女性限定。男性読者を集めても成果にならないので、タイトルとリードで
「30代女性」「子育てと両立」などの言葉を入れて、読者層を最初に絞る。

### 3. 本人NG

自己申込は成果にならない。自分で申し込んで体験談を書く、という手は使えない。

### 4. リスティングNGワードは「社名、サービス名、表記ゆれ」

これはリスティング広告（Google広告など）を出すときの話であって、
**ブログ記事のタイトルや本文でサービス名を書くのは問題ない**。
広告出稿をするなら「MySTAR」「マイスター」「よつば商事」系のワードは全部使えない。

### 5. 体験談を作らない

受講していないので、体験レビューは書けない。書いたら虚偽になるし、
ステマ規制（景表法）にも引っかかる。
記事の立ち位置は「調べてまとめた人」で通す。公式サイトや資料に書いてあることと、
自分の意見・比較軸だけで構成する。

### 6. 広告表示（PR表記）が必須

A8の規定で、広告と分かる表示をファーストビューなど「一般消費者が閲覧できる位置」に出す必要がある。
表示がないと提携解除や成果キャンセルの可能性がある。
記事タイトル先頭の `【PR】` ＋ 本文冒頭の注記、両方入れる。

## 数字の扱い（景表法）

PR文にある「最大70%還元」「実質月6,666円から」は、補助金の要件を満たした場合の話。
そのまま断定形で書くと不当表示になりうるので、記事では次のルールで書く。

- 「条件を満たした場合」「最大で」を必ず付ける
- 金額・還元率は**公式サイトで最新の数字を確認してから**書く（ドラフト内では `[[要確認]]` を付けてある）
- 補助金の支給可否・金額は個人の状況で変わる、と一文入れる
- 「必ず稼げる」「絶対に転職できる」は書かない

補助金の正式名称・要件は広告主資料（提携時に共有されたGoogleドキュメント）と
公式サイトで確認したうえで記事に反映する。うろ覚えで制度名を書かない。
