# リズムワーク

からだと気分に合わせて「今日やること」を決める、フリーランス向けのタスク管理アプリです。
生理周期・体調・育児などの状況を記録し、その日のエネルギーに合ったタスクだけを提案します。

## 使い方

`task-app/index.html` をブラウザで開くだけで動きます（サーバー不要・インストール不要）。
データはブラウザの localStorage にのみ保存され、外部には送信されません。

## 機能

- **ホーム** — 今日のエネルギー・気分・からだのサイン・使える作業時間を記録。周期の時期と、体調に合ったおすすめタスクを表示。「今日できたこと」でモチベーション維持。
- **タスク** — クライアント / 締切 / 見積時間 / 優先度 / 必要なエネルギー（軽い・ふつう・重い）でタスク管理。
- **周期** — カレンダーで生理開始日を登録。月経期・卵胞期・排卵期・黄体期・PMS注意期を自動判定し、次の生理を予測。
- **記録** — 直近14日のエネルギー / 気分グラフ、今週のふりかえり、よく出るサイン。
- **設定** — 周期の長さ・生理日数・PMS注意日数、バックアップの書き出し / 読み込み。

## おすすめタスクのロジック

1. 今日のエネルギーで扱えるタスクの重さを決める（低め→軽いのみ、ふつう→軽い+ふつう、良い以上→すべて）
2. 周期の時期でさらに絞る（月経期は軽いのみ、PMS注意期は重いを外す など。エネルギーが「良い」以上なら周期の制限は緩める）
3. 締切・優先度順に、今日使える作業時間の枠内で詰める（締切当日・超過のタスクは重さに関係なく表示）
