# 1キャラ→7商品 実践ワークブック

AI画像副業ロードマップ（1キャラを7商品へ展開して販売するまで）の実践用ページです。

| ファイル | 内容 |
| --- | --- |
| `index.html` / `style.css` / `script.js` | ワークブック本体。ブラウザで `index.html` を開くだけで動きます（ビルド不要） |
| [`../docs/ai-image-7products-roadmap.md`](../docs/ai-image-7products-roadmap.md) | 教材の全文原稿（POINT1〜7＋プロンプト20本） |

## ページに入っているもの

1. **基準キャラクターの設計メモ** — キャラ名・タイプ・固定ポイント・基本カラー・基準画像のファイル名を記録
2. **コピペ用画像プロンプト20本** — ①〜④基準キャラ設計／⑤〜⑨差分／⑩〜⑯7商品展開／⑰修正・⑱仕上げ・⑲告知画像・⑳サムネイル。1本ずつコピーボタン付き
3. **7商品展開テンプレート** — どの商品がどこまで進んだかのチェックリスト（進捗カウンタ付き）
4. **30日ロードマップ** — 1〜3日目のキャラ設計から28〜30日目の次シリーズ決定までのチェックシート

## 保存について

入力内容とチェック状態は `localStorage`（キー: `ai-image-7products-workbook`）に保存され、**同じブラウザの中だけ**に残ります。サーバーへは送信されません。別の端末やブラウザには引き継がれないため、大事なメモは別途控えてください。ページ下部の「メモとチェックをリセットする」で全消去できます。

`localStorage` が使えない環境（プライベートウィンドウ、サイトデータのブロック等）でも、プロンプトの閲覧・コピーは通常どおり動きます。

## 既存サイトとの関係

リポジトリ直下の「オンライン秘書タイプ診断」（`/index.html`）とは独立しています。このフォルダを消しても診断ページには影響しません。
